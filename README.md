## 🚀 Acerca del Proyecto

**TriForge API** ha sido diseñada para simplificar el flujo de trabajo de los desarrolladores. Centraliza un ecosistema de **6 utilidades clave** en una sola integración, eliminando la necesidad de depender de múltiples servicios externos. Cuenta con un sistema de autenticación y gestión de usuarios conectado a base de datos para garantizar un acceso seguro y personalizado.

## 🔐 Autenticación y Base de Datos

El sistema incluye un módulo de **Login y Registro de Usuarios**:
* Gestión de sesiones seguras.
* Almacenamiento persistente mediante base de datos.
* Endpoints protegidos para el consumo de las herramientas por usuario autenticado.
