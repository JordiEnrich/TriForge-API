## 🚀 Acerca del Proyecto

**TriForge API** ha sido diseñada para simplificar el flujo de trabajo diario de los desarrolladores. Centraliza un ecosistema de **6 utilidades clave** en una sola integración, eliminando la necesidad de depender de múltiples servicios externos. Cuenta con un sistema de autenticación y gestión de usuarios conectado a base de datos para garantizar un acceso seguro y personalizado.

---

## 🛠️ Las 6 Herramientas Incluidas

1. 🔄 **Conversor JSON a CSV y a SQL INSERT:** Transforma estructuras de datos rápidamente al formato que necesites para tus bases de datos o reportes.
2. 📋 **Validador y formateador de JSON:** Comprueba la sintaxis y da formato limpio a tus objetos JSON para evitar errores de estructuración.
3. 🔑 **Generador de claves API y HASHES:** Crea identificadores seguros y encriptaciones de forma rápida para tus desarrollos.
4. ⚡ **Probador de Endpoints:** Realiza pruebas directas sobre tus rutas y peticiones HTTP de manera centralizada.
5. 📝 **Gestor de tareas:** Permite gestionar y priorizar tareas o procesos dentro de tu flujo de trabajo.
6. 🎲 **Generador de datos de prueba:** Crea grandes volúmenes de datos de prueba (mock data) para rellenar bases de datos y realizar pruebas de rendimiento.

---

## 🔐 Autenticación y Base de Datos

El sistema incluye un módulo robusto de **Login y Registro de Usuarios**:
* Gestión de sesiones seguras mediante autenticación.
* Almacenamiento persistente en base de datos.
* Endpoints protegidos para que cada usuario registrado gestione sus operaciones de forma privada.
